## What Is Delta PC?

Delta PC is a Windows application for Roblox Lua injection and script execution, packaged as a compact desktop tool. It includes a script library in the same interface, allowing users to find and launch Roblox scripts without moving between separate programs. The overall focus is quick startup and routine desktop use.

The executor also provides a script queue that remains between sessions, batch execution, an integrated debugger, and automatic update support. Together, these components are aimed at users who prefer a single Roblox Lua executor for browsing, loading, and running scripts rather than managing multiple standalone utilities.
